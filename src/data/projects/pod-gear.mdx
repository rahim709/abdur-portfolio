# Premium Gaming Services Marketplace

## Description

Built a premium, bilingual e-commerce marketplace that connects competitive gamers with professional coaching, custom base layouts, masterclasses, and merchandise. The platform handles user authentication, subscription memberships, secure payments, and real-time scheduling — all wrapped in a polished, responsive experience designed to scale.

> 🚧 Currently in the active building phase.

## Tech Stack

- **Frontend:** Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS v4
- **Backend:** Express 5, TypeScript, MongoDB with Mongoose, Redis
- **Storage:** Supabase Storage
- **Payments:** Stripe (checkout, subscriptions, webhooks)
- **Scheduling:** Cal.com API integration
- **Auth:** NextAuth v5, JWT, bcrypt, OAuth (Google/Discord) + credentials
- **Forms & Validation:** React Hook Form, Zod
- **Animation & UI:** Framer Motion, Lucide React

## Key Features

- Full English/French language support with user-switchable locale and localized content across the marketplace
- Multi-game coaching marketplace with coach profiles, masterclasses, and 1-on-1 session booking
- Curated base pack marketplace with search, filtering, and secure checkout
- Membership subscription program with perks, discounts, and exclusive content
- Merchandise shop with size selection, cart, and checkout flow
- User dashboard with order history, favorites, loyalty points, and referrals
- Secure Stripe payments and subscription webhook handling
- Role-based admin dashboard for managing products, content, orders, and users
- Responsive, animated dark-themed UI with custom typography

## My Role / What I Built

Designed and developed the full-stack application, from the responsive frontend architecture and custom bilingual system to backend API integrations, payment flows, and admin tooling. Focused on clean, reusable components, type safety, performance, and a polished end-to-end user experience.
